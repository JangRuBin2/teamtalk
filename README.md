# TeamTalk

겉보기엔 평범한 사내 메신저 CLI인 AI 게임 모음입니다. 모든 게임은 Claude와 대화하면서 진행되고, 시계는 **실제 현재 시각**을 씁니다. 처음 실행할 때 출근·퇴근 시간을 등록하면 그 시간에 맞춰 게임이 돌아갑니다.

| 게임 | 내용 |
|---|---|
| 1. 사내 추리 | 사건이 터지면 동료 5명(각자 AI)에게 DM을 보내 심문하고 증거를 열람해서, **등록한 퇴근 시간 전까지** 범인을 찾습니다. 범인은 거짓말을 하고, 무고한 동료도 숨기는 비밀이 있습니다. |
| 2. 설득왕 | 출입증 없이 들어가기, 마감 주간 금요일 반차, 보안팀에게 관리자 권한 받기, 엘리베이터 30초 안에 대표 설득하기 등 6개 스테이지. 정해진 마디 안에 말로 설득해야 합니다. |
| 3. 메일함 생존기 | 최부장, 사수, 거래처가 보내는 업무 메일 10통에 답장하면서 평판과 스트레스를 관리합니다. 답장 결과가 다음 메일에 이어집니다. |
| 4. 서버 던전 | 15년 된 레거시 서버에 ssh로 접속한 신입 개발자가 되어, 리눅스 명령어로 좀비 프로세스를 처리하고 선배의 인수인계 문서를 찾습니다. 화면이 진짜 터미널처럼 보입니다. |
| 5. 같이하기 | 최대 4명이 사내 추리 사건을 함께 풉니다. 방장이 방을 만들면 나오는 6자리 초대 코드로 동료가 들어옵니다. |

모든 게임은 자동 저장되고, `/b`를 누르면 가짜 빌드 로그 화면으로 바뀝니다(보스키, Enter로 복귀).

## 다운로드와 실행

[Releases](../../releases) 페이지에서 내 OS에 맞는 파일을 받으세요.

| OS | 파일 |
|---|---|
| Windows | `teamtalk-windows.exe` (더블클릭) |
| Mac (M1~M4) | `teamtalk-mac-applesilicon` |
| Mac (Intel) | `teamtalk-mac-intel` |
| Linux | `teamtalk-linux` |

Mac은 서명 안 된 파일을 막기 때문에 처음 한 번만 아래를 실행하세요.

```bash
chmod +x teamtalk-mac-applesilicon
```

```bash
xattr -d com.apple.quarantine teamtalk-mac-applesilicon
```

```bash
./teamtalk-mac-applesilicon
```

Windows에서 SmartScreen 경고가 뜨면 "추가 정보 → 실행"을 누르세요.

## 접속 방식

- **접속 코드 (중계 서버):** 중계 서버 주소를 넣어 빌드한 파일은 처음 실행할 때 접속 코드를 묻습니다. API 키는 중계 서버에만 있고 게임 파일에는 들어가지 않습니다. 서버 설정은 [relay/README.md](relay/README.md)를 보세요.
- **개인 API 키:** 중계 서버 없이 빌드한 파일은 Anthropic API 키를 묻습니다. 설정 메뉴에서 언제든 바꿀 수 있습니다.

설정은 `~/.teamtalk/config.json`에 저장됩니다.

## 같이하기 (최대 4명)

1. 방장: 메뉴 `5` → `1. 방 만들기`. 화면에 초대 코드(예: `K7Q2MX`)가 나옵니다.
2. 동료: 메뉴 `5` → `2. 방 참가` → 초대 코드 입력. 참가자는 접속 코드도 API 키도 필요 없습니다.
3. 다 모이면 방장이 `/start`.

협력 규칙:
- 용의자 AI와의 DM은 **사람마다 따로**입니다. 각자 알아낸 걸 `#조사팀`(0번)에서 맞춰봐야 합니다.
- 증거 자료는 **사람마다 나눠서** 배정됩니다. 내 자료는 `/e 번호`로 보고, `/share 번호`로 팀에 공유합니다.
- 범인은 `/vote 번호 근거`로 투표합니다. 접속한 전원이 투표해서 과반이 나오면 보고되고, 갈리면 다시 의논합니다.
- 마감은 방장이 등록한 퇴근 시간입니다. 접속이 끊겨도 같은 닉네임으로 다시 들어오면 이어서 할 수 있습니다.

AI 호출은 방장 쪽 접속 코드로 나갑니다. 같이하기는 중계 서버가 연결된 버전에서만 할 수 있습니다.

## 사내 추리 명령어

| 입력 | 동작 |
|---|---|
| `1`~`5` | 해당 동료와 DM 열기. 그다음 그냥 입력하면 메시지가 전송됩니다 |
| `0` | 메인(#general)으로 돌아가기 |
| `/e`, `/e 2` | 증거 목록 보기 / 증거 열람 |
| `/memo 내용` | 메모 추가 (`/memo`만 입력하면 메모 보기) |
| `/log` | 현재 DM 전체 대화 보기 |
| `/accuse` | 범인 지목 (게임 종료, 추리 근거로 등급 S~C) |
| `/b` | 보스키 |
| `/q` | 저장하고 게임 메뉴로 |

퇴근까지 30분도 안 남았을 때 시작하면 시간 제한 없는 연습 모드로 할 수 있습니다.

## 모델 설정

| 용도 | 기본 모델 |
|---|---|
| 사건 생성 | `claude-opus-5-5` (한 판에 한 번, 품질이 가장 중요) |
| 용의자 DM, 설득왕, 메일, 서버 던전, 추리 채점 | `claude-haiku-5-5` (짧은 대화라 빠르고 저렴) |

환경변수로 바꿀 수 있습니다. `TEAMTALK_MODEL`은 사건 생성용, `TEAMTALK_NPC_MODEL`은 대화용입니다. 중계 서버를 쓴다면 서버의 `ALLOWED_MODELS`에도 그 모델이 있어야 합니다.

```bash
TEAMTALK_NPC_MODEL=claude-opus-5-5 ./teamtalk-linux
```

## 빌드와 릴리즈

Go 1.25 이상이 필요합니다.

```bash
./build.sh
```

`dist/`에 4개 플랫폼 파일이 생깁니다. 중계 서버 주소를 넣으려면 `RELAY_URL=https://... ./build.sh`로 실행하세요.

릴리즈는 GitHub의 **Actions → release → Run workflow**에서 버전(예: `v0.3.0`)을 입력하면 만들어집니다. 레포 변수 `RELAY_URL`이 있으면 그 주소가 들어간 파일이 빌드됩니다.
