# 금요일 밤 운영 서버 다운 사건

## 개요
지난 금요일 밤 23시 12분, 운영 서버의 데이터 디스크가 통째로 비워지면서 서비스가 4시간 동안 멈췄다. 서버 로그에는 공용 계정 deploy로 정리 스크립트가 '--force' 옵션과 함께 운영 서버에서 실행된 흔적이 남아 있다. 공용 계정이라 누가 했는지 바로는 알 수 없다.

## 범인
B

## 동기
디스크 사용량 경고를 몇 주째 무시하다가 월요일 성능 리포트 마감을 앞두고 몰래 정리하려 했다. 테스트 서버에 돌린다는 게 운영 서버에 실행해 버렸고, 책임이 무서워 숨기고 있다.

## 수법
친구 결혼식 피로연에서 20:30에 먼저 빠져나와 집에서 회사 노트북으로 VPN에 접속(23:02)했다. 공용 계정 deploy로 운영 서버에 들어가 23:05에 정리 스크립트를 실행했고, 23:12에 서비스가 다운되자 바로 접속을 끊었다.

## 결정적 모순
{B}는 "금요일 밤엔 결혼식 피로연에 끝까지 있었고 노트북도 안 켰다"고 주장하지만, 피로연은 21시에 끝났고 {B}는 20:30에 먼저 나갔다. VPN 기록상 23:02에 장비 'MBP-14-개발-07'이 접속했고, 자산 관리 대장에서 이 노트북의 사용자는 {B}다.

## 타임라인
- 금요일 16:40 - {C}가 배포 후 디스크 사용량 91% 경고를 보고도 보고하지 않음
- 금요일 17:10 - {B}가 "디스크 정리 스크립트 주말에 내가 돌릴게"라고 말함
- 금요일 18:30 - {B}와 {E}가 동료 결혼식 피로연 참석
- 금요일 20:30 - {B}가 "회사 일 좀 봐야 해서"라며 피로연에서 먼저 나감
- 금요일 21:00 - 피로연 종료
- 금요일 22:50 - {D}가 운영 DB에서 대용량 쿼리 실행 (규정 위반)
- 금요일 23:02 - 장비 MBP-14-개발-07 VPN 접속
- 금요일 23:03 - {D}가 결과를 보려고 접속했다가 10.0.3.27에서 열린 deploy 세션을 봄
- 금요일 23:05 - deploy@10.0.3.27 에서 정리 스크립트 --force 실행
- 금요일 23:12 - 서비스 다운, 장애 알림 발송 시작
- 금요일 23:13 - MBP-14-개발-07 VPN 접속 종료
- 토요일 00:20 - 당직 {A}가 알림을 처음 확인하고 복구 시작

## 용의자

### A
- 직급: 과장
- 부서: 인프라팀
- 성격 힌트: 베테랑인 척하지만 허세가 있음
- 주장: 금요일 당직이었고 23:40에 알림을 받자마자 복구를 시작했다.
- 실제: 알림은 23:15부터 울렸지만 술 마시고 자다가 00:20에야 확인했다. 복구는 제대로 했다.
- 비밀: 당직 중에 술을 마시고 잠들었다.
- 단서:
  - 서버 로그를 보면 스크립트는 공용 계정 deploy로, 내부 VPN 대역 IP 10.0.3.27에서 실행됐다.
  - deploy 계정 비밀번호는 개발팀 대리급 이상과 인프라팀만 안다. 신입인 {C}는 모른다.

### B
- 직급: 대리
- 부서: 백엔드개발팀
- 성격 힌트: 일 잘한다는 평판에 집착, 실수를 인정 못 함
- 주장: 금요일 밤엔 동료 결혼식 피로연에 끝까지 있었고 노트북도 안 켰다.
- 실제: 20:30에 피로연에서 나와 23:02에 VPN 접속, 23:05에 운영 서버에서 정리 스크립트를 실행했다.
- 비밀: 디스크 경고를 몇 주째 무시하고 리포트에는 '이상 없음'이라고 써왔다.
- 단서:
  - {D}가 금요일 밤 늦게 운영 DB에서 무거운 쿼리를 돌렸다는 걸 안다. (의심을 돌릴 때 쓴다)

### C
- 직급: 사원
- 부서: 백엔드개발팀
- 성격 힌트: 입사 3개월 차 신입, 잔뜩 겁먹음
- 주장: 금요일 오후 배포만 하고 18시에 퇴근했다. 서버 다운은 모르는 일이다.
- 실제: 주장과 같다.
- 비밀: 배포 후 디스크 사용량 91% 경고를 보고도 아무에게도 보고하지 않았다.
- 단서:
  - 금요일 17시쯤 {B}가 "디스크 정리 스크립트 주말에 내가 돌릴게"라고 하는 걸 들었다.
  - 정리 스크립트는 --force를 붙이면 테스트/운영 확인 질문 없이 바로 실행된다.

### D
- 직급: 대리
- 부서: 데이터팀
- 성격 힌트: 냉소적이고 말이 짧음
- 주장: 금요일 밤 22:50에 쿼리 하나 돌리고 결과만 확인하고 잤다.
- 실제: 주장과 같다. 다만 그 쿼리를 테스트 DB가 아니라 운영 DB에서 돌렸다.
- 비밀: 퇴근을 빨리 하려고 규정을 어기고 운영 DB에서 대용량 쿼리를 실행했다.
- 단서:
  - 23시 3분쯤 결과를 보려고 접속했을 때 10.0.3.27에서 열린 deploy 세션이 하나 있었다.

- 성격 힌트: 모두와 두루두루 친한 중재자
- 주장: 금요일 밤엔 {B}와 같은 결혼식 피로연에 있었다.
- 실제: 21시 피로연이 끝날 때까지 있었다.
